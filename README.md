# 🌸 Iris Flower Classification

This project is developed as part of the Data Science Internship at CodeAlpha.

## 📌 Project Overview
The objective of this project is to classify Iris flower species using Machine Learning algorithms based on flower measurements.

## 🚀 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📊 Features
- Data preprocessing
- Data visualization
- Machine learning model training
- Accuracy evaluation
- Confusion matrix visualization
- Prediction system

## 🤖 Machine Learning Algorithm
- Random Forest Classifier

## 📈 Model Accuracy
The model achieved high accuracy on the test dataset.
